# 📱 Farzandingiz maktabda — telefoningizda

**Hurmatli ota-ona!** Maktabimizning Telegram boti farzandingiz haqidagi muhim xabarlarni **o'zi** yuboradi va istalgan vaqtda jadval, davomat va baholarni ko'rsatadi. Bepul, ro'yxatdan o'tish shart emas.

## 1. Qanday ulanish mumkin (1 daqiqa)

**1-usul — QR kod.** Sinf rahbari bergan kartochkadagi QR kodni telefon kamerasi bilan skanerlang → Telegram ochiladi → **Start** tugmasini bosing.

**2-usul — telefon raqami.** Telegram'da botni toping, **Start** bosing, so'ng **«📱 Raqamni ulashish»** tugmasini bosing. Raqamingiz maktabda yozilgan bo'lsa, farzandlaringiz avtomatik ulanadi.

Bot javob beradi: **«✅ Tabriklaymiz! Endi farzandingiz haqida hamma narsa shu yerda»**. Tamom!

## 2. Bot o'zi nimalarni yuboradi

| | Xabar | Qachon |
|---|---|---|
| 🔴 | Farzandingiz darsga kelmadi | Darhol |
| 🟡 | Kechikib keldi | Darhol |
| 📘 | Yangi baho | Baho qo'yilganda |
| 📢 | Maktab e'loni | E'lon chiqqanda |
| 📅 | Ertangi dars jadvali | Har kuni kechqurun (19:00) |

🌙 Kechasi (22:00–07:00) bot sizni bezovta qilmaydi — xabarlar ertalab keladi.

## 4. Farzandingiz kasal bo'lsa — 🤒 Sababli ariza

Bosh menyuda **«🤒 Sababli ariza»** → sanani tanlang → necha kun → sabab → izoh → shifokor ma'lumotnomasining rasmi (bo'lsa) → **Yuborish**. Sinf rahbari tasdiqlasa, o'sha kunlar davomatda **«sababli»** bo'ladi va bot sizga xabar beradi.

## 5. Savollar

- **Xabar kelmayapti?** ⚙️ Sozlamalar'da o'sha xabar turi yoqilganini tekshiring. Botni bloklamaganingizga ishonch hosil qiling.
- **Ikki farzandim bor.** 👨‍👩‍👧 Farzandlarim → ➕ Farzand qo'shish → ikkinchi farzand kartochkasidagi kodni yuboring.
- **To'xtatmoqchiman.** Botga `/stop` yuboring. Qayta ulanish uchun yana QR kodni skanerlang.
- **Ma'lumotlarim xavfsizmi?** Ha. Siz faqat **o'z farzandingiz** haqidagi ma'lumotni ko'rasiz; boshqa hech kim uni ko'ra olmaydi.

<sub>Savol bo'lsa — sinf rahbaringizga yoki bot orqali «💬 Maktabga yozish» bo'limiga murojaat qiling.</sub>
